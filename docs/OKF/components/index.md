# Components

* [BaseButton](base-button.md) - The shared WPF-style button implementation used by several public button variants.
* [BlankDropDown](blank-drop-down.md) - A low-level dropdown shell with templated display and panel content.
* [BottomNavigationBar](bottom-navigation-bar.md) - A visual container that fixes navigation items into a horizontal bottom bar.
* [BranchComponent<T>](branch-component.md) - The recursive branch renderer used internally by TreeMenu<T>.
* [Callout](callout.md) - A positioned overlay anchored to a target element ID with optional light dismiss.
* [CheckBox](check-box.md) - A WPF-style binary check control with configurable box placement.
* [CheckboxGroup<T>](checkbox-group.md) - A generic data-driven group that renders each item as a CheckBox or Toggle.
* [Chip](chip.md) - A single chip with input, choice, filter, or action presentation.
* [ChipSet<TItem>](chip-set.md) - A generic collection of editable/selectable chips with optional new-item creation.
* [Choice<T>](choice.md) - A BlazorFluentUI component.
* [ChoiceGroup<T>](choice-group.md) - A generic single-selection radio group using cascading coordination with Choice children.
* [CompoundButton](compound-button.md) - A button variant with primary text and a secondary descriptive line.
* [DefaultButton](default-button.md) - The standard primary or secondary action button wrapper.
* [DropDown<TItem>](drop-down.md) - A generic single- or multi-select dropdown with optional item templates and grouped DropDownItem data.
* [Expander](expander.md) - A collapsible header/body container with bindable open state.
* [FitText](fit-text.md) - A JavaScript-assisted text container that scales content to fit configured bounds.
* [FloatingActionButton](floating-action-button.md) - A floating action surface that can render an image, icon, text content, or a combination.
* [HyperLinkButton](hyper-link-button.md) - An anchor-based button with target selection and optional busy animation.
* [Icon](icon.md) - A wrapper for the bundled Office Fabric icon font using IconTypes.
* [IconButton](icon-button.md) - A compact icon-only clickable control.
* [Label](label.md) - A styled label element with hidden and disabled states.
* [LightDismiss](light-dismiss.md) - A fixed backdrop layer that closes its owning overlay when clicked.
* [Modal](modal.md) - A JavaScript-assisted modal with header/content fragments and optional light dismissal.
* [NavButton](nav-button.md) - A BaseButton wrapped in an anchor when Href is provided.
* [NavigationItem](navigation-item.md) - A clickable bottom-navigation entry that renders an icon or image and navigates to a URL.
* [Persona](persona.md) - A user identity display with initials or image, name, title, and configurable sizing.
* [PostButton](post-button.md) - A native form-posting button that submits hidden name/value fields to a URL.
* [SpinButton](spin-button.md) - A whole-number or decimal input with buttons and mouse-wheel increment/decrement behavior.
* [Spinner](spinner.md) - A loading indicator with size and label-position options.
* [SplitButton<TItem>](split-button.md) - A generic primary action plus callout menu for choosing an item.
* [Tab](tab.md) - A child tab page registered with a parent Tabs component through a cascading parameter.
* [Tabs](tabs.md) - A tab header and content host with an index-based initial selection.
* [TemplateButton](template-button.md) - A button-like container whose visual content is supplied by a RenderFragment.
* [TextField](forms-text-field.md) - An InputBase<string>-derived text field for EditForm validation and optional masking.
* [TextField](text-field.md) - The standalone WPF-style text input with binding, masking, input types, and character limits.
* [Theme](theme.md) - The application theme boundary that emits palette and semantic CSS custom properties.
* [TinySpinner](tiny-spinner.md) - A compact spinner variant that shares the Spinner parameter contract but omits label markup.
* [Toggle](toggle.md) - A WPF-style binary toggle switch with bindable IsChecked state.
* [TreeMenu<T>](tree-menu.md) - A generic virtualized hierarchical menu with lazy child loading and selection.
* [ValidationInput](validation-input.md) - A minimal InputBase<string> input that participates in EditForm validation.
